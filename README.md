# Monitor de IA

Releases del **Monitor-IA.exe**, el banco de pruebas de la IA de Warlords III.

- Se baja de [Releases](https://github.com/elcoprofago/Monitor-IA/releases/latest) y va en la carpeta `ia` de
  Warlords-updater, junto a `datos.db` y `tanda.ini`.
- Para actualizarlo: ruedita de configuración → **Buscar actualización**.
- El código fuente vive en [Warlords-updater](https://github.com/elcoprofago/Warlords-updater), carpeta
  `ia/monitor-ia`; las releases se publican con `python ia\monitor-ia\publicar.py`.
